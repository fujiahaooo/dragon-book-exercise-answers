# Exercises for Section 1.6

### 1.6.1

For the block-structured C code below, indicate the values assigned to w, x, y, and z.

> 根据下面块结构的C代码，推断 w,x,y,z 的值

```
int w, x, y, z;
int i = 4; int j = 5;
{
  int j = 7;
  i = 6;
  w = i + j;
}
x = i + j;
{
  int i = 8;
  y = i + j;
}
z = i + j;
```

#### Answer

w = 13, x = 11, y = 13, z = 11.
